# thefantasylab.io — Claude Project Instructions

## Brand Voice
- Tone: Confident, friendly, and straightforward. Like a knowledgeable friend 
  who plays fantasy sports — not a corporate product page.
- Reading level: 8th grade. Casual fans should understand everything instantly.
- Always speak directly to the user: use "you" and "your"
- Lead with benefits, never features
- Be concise — if it can be said in 5 words, don't use 10

## Words We Use
- "tools" not "solutions"
- "your league" not "the platform"
- "fantasy manager" not "user"
- "win your league" as the ultimate outcome
- Short punchy CTAs: "Try it free", "See your matchups", "Get started"

## Words We Never Use
- seamless, robust, leverage, utilize, cutting-edge, next-generation
- Any phrase that sounds like enterprise software marketing

## Product Context
- These are Yahoo Fantasy Sports tools
- Target user: casual to mid-level fantasy sports players
- Key value: saves time, gives an edge, easy to understand
- No install required — web-based tools

## SEO Keywords to Weave In Naturally
- Yahoo Fantasy Sports tools
- Fantasy football tools
- Fantasy baseball tools  
- Fantasy sports manager
- Fantasy league tools

## Code Rules
- Preserve all existing CSS classes and JS hooks when editing HTML
- Never break existing functionality
- SEO: every page needs unique title, meta description, and canonical tag
